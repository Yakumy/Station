## Corrections for implementation

1. Service IPC must use the now-proven direct service-owned target. Do not use
   `keepLoaded` merely to hide the routing problem:
   the host also uses that flag to retain services across plugin hot-reloads.
2. Silent-send number keys are already Omarchy defaults. Include them in the
   intentional replacement table. Live output and `default/hypr/bindings/tiling.lua`
   agree. On 2026-10-04 the author explicitly approved replacing “Move grouped
   window focus left/right” too: `CTRL+SUPER+←/→` belongs in the intentional
   replacement set and must work immediately on installation.
3. Exact installed popup tokens are `Color.popups.background`, `.text`, `.border`;
   menu tokens are `.background`, `.text`, `.border`, `.scrim`,
   `.selectedBackground`, `.selectedText`, `.selectedBorder`.
   Global `Color.foreground`, `.accent`, `.urgent` exist. `Color.bar` has
   `.background`, `.text`, `.active`; it has no `.foreground`.
   The injected Display `bar.foreground` is a separate API. Use that bar API
   where available, and `Color.foreground` as its fallback.
4. Copy Display's component structure, not its raw values: its existing code
   includes some numeric spacing/font adjustments that Station's stricter token
   requirement disallows. Wrap dimensions in `Style.space`, use `Style.font`
   and `Style.spacing`, and retain the shared `BorderSurface`/`Border` model.
5. Restore an already-enabled bar widget with `omarchy bar move`, not `put`.
   `put` is explicitly idempotent and preserves the widget's current location.

## Reproduce without changing the desktop

```
node --test test/m0/*.test.mjs
node tools/v2/probe-platform.mjs > /tmp/station-m0-evidence.json
python3 tools/v2/check-qml.py
```

The second command needs access to the live session sockets. It uses argv
arrays and never dispatches, reloads, installs or edits desktop config. Its
monitor report omits EDID/serial fields. Source hashes and all 20 timing samples
are in `M0-evidence.json`. Source-contract tests skip on CI without Omarchy;
that is explicitly not a platform pass.

The QML check requires the Wayland session: the offscreen backend cannot load
`KeyboardPanel`. It launches a separate temporary Quickshell configuration,
compiles the fixture without instantiating its Panel or Service, then terminates
that process. Observed result: `M0_COMPONENTS_READY`. This is a compilation
check, not proof of interactive behaviour. It does not restart the user's shell.

The v2 CI workflow runs the theme-check regression test now and checks all
text sources under `yakumy.station/` when the runtime exists. The checker fails
on hex palettes (including short/alpha forms) and symlinks. A missing runtime
is labelled pending, not a successful palette audit. Additional token checks
for spacing/fonts/radii belong with the actual QML implementation.
